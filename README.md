## Projects

### 1. OWASP Juice Shop — Web Application Security Testing

**Environment:** Local, isolated Docker lab

**Objective:** Practise web application security testing and understand common security weaknesses in an intentionally vulnerable training application.

**Activities:**
- Configured a local Docker-based security testing environment.
- Used Nmap to identify open ports and detect services on the local target.
- Analysed HTTP requests and responses using Burp Suite.
- Used cURL to send HTTP requests and inspect server responses.
- Tested access control using two self-created lab accounts.
- Observed cross-user shopping basket data disclosure, consistent with an IDOR/Broken Object Level Authorization vulnerability.
- Tested application responses to different search inputs and examined error messages.
- Documented findings and studied appropriate security remediation methods.

**Scope:** Testing was performed against my own local training environment. These exercises do not represent a penetration test of a real company or production application.

**Project documentation and evidence:** More detailed reports and sanitised screenshots will be added to this repository.
